# Architecture
---
De website moet een toegangkelijk zijn voor iedere bezoeker, dit betekend geen ingewikkelde navigatie of parralax, dit betekend geen complexe inlog procedure voor het weergeven van de content, en voornamelijk 1 pagina met de hoofd informatie van de website.

```
website/
├── index.php                 # Main website (landing + stacked pages)
├── config/
│   └── database.php          # Database connection and helper functions
├── admin/
│   ├── index.php             # Admin login page
│   └── dashboard.php         # Admin dashboard for content management
├── uploads/
│   └── covers/               # Magazine cover images (create this folder)
├── css/                      # Additional stylesheets (optional)
├── js/                       # Additional JavaScript files (optional)
└── README.md                 # Project documentation
```

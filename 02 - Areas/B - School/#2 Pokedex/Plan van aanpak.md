Site:
--
De bedoeling voor de site is dat er een digitale tafel komt waar klanten eten op kunnen zetten  met een pokedex waar klanten pokemon in kunnen zetten.

mijn idee voor de site is dat we een digitale tafel hebben waar de gevangen pokemon van de klant samen kunnen dineren met de klant of met de pokemon van andere klanten.

klanten kunnen wanneer ze binnenkomen en voor het eerst inloggen op de site een "starter pokemon" kiezen (1st gen)
^
digitale menu kaart beinvloed door de pokemon die de klant kiest

de mockups en design van de site staan als volgt in text beschreven
-wanneer je de site opzoekt kom je meteen in een inlog scherm waar je een account kunt aanmaken of uiteraard inloggen. 
-bij het inlog scherm heb je een geanimeerde naar beneden scrollende gif met wat pokemon
-wanneer je ingelogd bent kom je op het "home scherm" waar je je pokedex ziet, welke pokemon -je hebt en in een sidebar welke de op dit moment ingelogde klanten hebben.
-je kunt naar onder scrollen naar een tweede scherm die word getransitioned met een soort parralax effect. 
-hier staat de tafel waarin je je pokemon kan zien dineren. 

Random generation
--
als je klaar bent met je eten (of na iedere maaltijd) komt de serveerster naar je tafel met een terminal waar een randomly generated QR code op staat die je kan scannen, aan deze QR code is een puc code verbonden (ook randomly generated) die je kan inleveren voor een "spin" in deze spins kun je een van 151 pokemon krijgen, je kan nooit een pokemon 2x krijgen

OF

we hebben een spin system waar je pokemon wel dubbel kan krijgen, dit zou betekenen dat we pokemon rarity levels kunnen geven, een charizard zou dus zeldzamer zijn dan een magikarp. als je een pokemon dan dubbel krijg kun je deze verkopen voor coins die je later kunt gebruiken om korting te krijgen in het restaurant.

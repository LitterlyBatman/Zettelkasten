 Hieronder volgt de aanpak voor aankomende challenge
--
Deze challenge periode gaan we een webshop maken verbonden aan een auto dealer. Deze webshop moet voldoen aan een kortings code systeem dat word geactiveerd door het spelen van een interactieve game. uiteraard moet deze website ook een zoekmachine bevatten speciaal voor het zoeken van Auto's

denk aan zoeken op:
- merk
- model
- bouwjaar
- deuren

GAMIFICATION:
de website moet voorzien worden van een mini-game waar een klant kortings codes en gratis producten mee kan winnen. Play to win!

De webshop van de showroom kan ook accecoires bevatten soals schoonmaakspullen en andere interieur accecoires.

Aangezien deze challenge een job hunt is is het belangrijk dat we ons goed organiseren als bedrijf, daarom moeten we als groepje een slogan bedenken bij ons logo

We zijn op de conclusie gekomen dat we de site in HTML en CSS gaan programmeren met JS add-ons.

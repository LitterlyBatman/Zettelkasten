# Quest

Be able to ping a task in a radius area other people may complete in return for a small fortune.

Tasks like mowing the lawn, washing the car, maybe painting a room or doing groceries. would all be able to be shared. 

When opening the app the user will be asked if they want to give up a task or complete one. When the app is installed and a quest is put up in the users area the user will receive a notification asking if they are up to the task and would like to complete it. The offered amount will be displayed, the difficulty of the quest and the distance;. Other necessities like name, adres, details about the quest, directions and supplies will be listed on the page of the quest. accessed when clicked on the notification. The app will contain a browse tab where listed quests will be displayed available for completion. 

Some quests will require more than one participant. this will be a core feature of the app. The user uploading the quest will be able to select if the quest takes more than one

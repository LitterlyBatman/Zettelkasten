# Ha.Bot

The goal with creating Ha.Bot is to create a self improvement app (possibly) powered by AI

The first goal to the start-up of the project is to create a habit building app (hence the name) thats totally free to use. We're gonna take inspiration from apps that already exist so we can make ours better!

Base Functions
--
- The app needs to have a home-screen that displays your newly found habits you want to improve on for the day. These are custom habits of which you can add as many as you would like to track. 
- weekly habits that track each week instead of each day, this can be completed randomly whenever or can be attached to a day each week.
- The app also needs to have a week and year function in which you can set goals for yourself. things that don't have to be habits but things you want to accomplish
- we should also add a more detailed schedule like: morning, afternoon, evening and night habits that have their own UI.

^ these are basically the features the app needs to function properly and be usefull enough but not outstandingly in-depth. these are the first goals we need to complete to get a working app that could be published and later expanded or be used as a platform to build up on before release to a competitive advantage.

Future Funtions

- a feature that let's you plan a week ahead to have habit's/reminders show up on the dates you need them to be in advance.

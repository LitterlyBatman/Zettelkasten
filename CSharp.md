# CSharp

C#, een programmeer taal ontwikkeld door microsoft op het .NET framework. Een van de populairste en meest gebruikte programmeer talen op aarde. Het word voor vanalles gebruikt van simpele console, mobile en web applicaties tot API's, Games en nog veel veel meer. Makkelijk te leren, gebruiken en met een enorme community is het de ideale programmeer taal.

De taal lijkt heel erg op C++ en Java wat betekend dat het makkelijk is voor ontwikkelaars om te switchen tussen talen. C# is een OOP (object oriented programming) taal

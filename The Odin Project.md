# The Odin Project

The Odin Project is een open source, community gerichte "opleiding" gefocust op het leren van full stack development. Van 0 naar 100 in prorgammeren is geen makkelijke taak en gaat om veel meer dan alleen een taal kunnen. Het gaat om je denkweize en mindset, dit is wat Odin wilt meegeven. Leren denken als een programmeur.

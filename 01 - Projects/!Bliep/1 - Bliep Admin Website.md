
De website, Bestaande uit een dashboard, geinspireerd door de Linux windows managers. Op dit dashboard kan de Docent een selectie divs pinnen en constant overzicht hebben op deze pagina's. Daarnaast zijn er andere toegangbare pagina's die toegankelijk zijn vanaf de navbar. Deze forms kunnen ook allemaal gepinned worden aan de home screen wat het volledig customisable maakt.

# v01 

De eerste versie van de website word gerealiseerd in (PHP) HTML/CSS/JS omgeving opgebouwd.

De website bestaat uit het dashboard:
	- De verticaal gestructureerde navigatie bar
	- 3 [iFrame] vakken waarin de gebruiker forms kan plaatsen om te bekijken.
	- een header waar de profiel kaart, tijd, en status worden weergeven.

De navbar is op dit moment een template die we laten kunnen aanpassen op de gewenste manier.
